Inspect a library without opening the plugin

Open a JSON report from corpus-health inspect, or start tools/library-inspector.py to inspect a file and view it here.

The default report contains structural metadata and static script bindings. Initialization is optional. Audio, runtime callbacks and native equivalence remain unverified until separately measured.

Reports stay in this browser’s memory. No uploads, analytics or external assets. Source text appears only when explicitly requested during inspection.
