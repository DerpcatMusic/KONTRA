# Native UI runtime boundary probe

Run `lua5.4 tools/probe_native_ui.lua tests/fixtures/native-ui-plain connection` for the authored model fixture. With a privately extracted resource directory, use `lua5.4 tools/probe_native_ui.lua <native-ui-root> use_connection` to execute the unchanged library connection module. The probe loads ordinary Lua `.nui` resources, including directory `init.nui`, and checks scalar host reads/writes and pull-based state/computed values. The fixture retains declared geometry/background metadata.

This is a developer feasibility probe, not the plugin runtime or a renderer. Its host exposes one authored scalar control; it does not deliver real KSP callbacks. Unsupported host APIs and extended component syntax produce errors. In the actual Conflux corpus, Lua 5.4 and LuaJIT both accept 31 of 134 modules and reject 103, including `main.nui:37` at `@ui.ZStack`. A portable Lua runtime alone cannot execute that extended frontend. No source rewriting, component scraping or bitmap substitution is performed.

Current official Komplete UI documentation describes the newer `.kscript` language, rather than this legacy Lua-based `.nui` syntax: [Language Tour](https://developer.native-instruments.com/komplete-ui/docs/LanguageTour/). Once a compatible legacy frontend is available, a maintained embedded runtime such as [mlua](https://github.com/mlua-rs/mlua) can supply portable Lua execution, memory limits and instruction hooks. There is no embedded Lua dependency in KONTRA yet; the installed system Lua is used only by this explicit developer command.
