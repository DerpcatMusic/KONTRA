# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Static HTML/CSS on GitHub Pages, explicitly selected by the user. The product itself is a native Rust sampler.

## Users
Musicians evaluating KONTRA, people installing nightly builds, and contributors reviewing compatibility and priorities.

## Product Purpose
Provide a professional public home for KONTRA, practical documentation and a full evidence-based roadmap.

## Capabilities and Constraints
Nightly alpha application for Windows, macOS and Linux, in CLAP, VST3 and standalone forms. Kontakt and UVI/Falcon are current parallel development tracks. Opus/EastWest, HALion, HISE and other sampler frontends are next. Feature support is generated from committed implementation probes, ledgers and verification records on every main commit; historical audit dates and architecture checkpoints do not define current priorities. The public browser inspector uses the shared Rust inspector on user-selected local files, with read-only access, load-stage diagnostics and authored UI-layout records. Audio playback, native UI fidelity, artwork rendering and unresolved stock/grid layout remain outside the browser check. Source, targeted checks and release artifacts remain distinct.

## Brand Commitments
KONTRA name; quiet professional presentation connected to the native graphite UI. User requests a Native Instruments-like level of craft and supplies the application screenshot. Build directly from that reference, without an image mockup.

## Evidence on Hand
README.md, docs/FEATURES.md, docs/COMPATIBILITY.md, docs/architecture-v2/PRODUCT.md, PLAN.md and HANDOFF.md, release assets and the supplied screenshot. No invented endorsements, dates or performance claims.
