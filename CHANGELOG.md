# Changelog

Every release and what changed in it is on the
[releases page](https://github.com/DerpcatMusic/KONTRA/releases): what you can
hear, see or measure first, each line linked to its pull request and author,
then the internal work.

- **Versions** are `MAJOR.MINOR.PATCH`. A release with a new feature raises
  MINOR; a release with only fixes and internal work raises PATCH. MAJOR is the
  engine generation (3 today).
- **A release is cut once a day** when something that ships has changed, and
  on demand. Nothing here is written by hand: the notes are the `Release note:`
  lines of the pull requests merged since the previous release.

How a change gets from a pull request into the notes:
[CONTRIBUTING.md](CONTRIBUTING.md#pull-requests-commits-and-releases).

The hand-written notes of the 0.3 series (the previous engine) are kept in
[docs/history/CHANGELOG-0.3.md](docs/history/CHANGELOG-0.3.md).
