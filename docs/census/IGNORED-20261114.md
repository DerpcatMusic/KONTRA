# What the translators drop, 2026-11-14

`tools/ignored-census.py`: `kontra-inspect load` of all 682 Kontakt instruments and 660 UVI programs
(corpus build, nice 19, 3 jobs, 0 errors). Each `ignored …` diagnostic is a stored field, chunk or XML
attribute the reader parses and no translator code reads. Editor-only items are marked cosmetic in code
and stay quiet.

First run, every stored field not read: 444 distinct items, 190,445 (instrument, item) rows. After
marking script state, versions, editor state and defaults as cosmetic: 20 items, 9,564 rows. The rest
are real gaps, ranked below by instruments. Impact is a guess; none was measured against Kontakt or UVI.
