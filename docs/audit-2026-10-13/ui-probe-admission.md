# UI probe admission

Accepted defect scope: `ui-library-sweep-fail-closed-probe-admission` — the library sweep previously admitted a zero-test invocation with exit code zero as a passed UI benchmark, even when the requested historical test and all measurements were absent.

The driver retains `ui::audit::tests::real_instrument_frame_benchmark` and requires exact ignored-test discovery before creating the output directory or launching cases. Each admitted case must establish exactly one invocation of that test, one passing libtest result, matching case metadata, and every required steady/changing frame stage with finite timings and the requested sample count. GPU admission requires a discrete or integrated adapter and GPU stage evidence; explicit CPU reference admission requires CPU stages. Requested callbacks additionally require native-worker counts and publication/render timings.

An explicit benchmark skip remains `skipped` when that exact test passed once and provided its skip reason and selected program. A successful process with missing, malformed, or mismatched evidence becomes `invalid_probe`, records a diagnostic, and makes the sweep exit unsuccessfully. Failed and timed-out processes retain their existing failure statuses.

Validation: `python3 -B tools/test_ui_library_sweep.py` — 18 synthetic standard-library tests passed in the coordinator run. All subprocess calls in these tests were mocked. The tests cover absent discovery before artifacts, zero/different/duplicate/ignored test transcripts, complete one-test evidence, explicit skips, missing/nonfinite measurements, case mismatch, software adapters, callback evidence, malformed JSON, and driver exit statuses. The coordinator also ran the driver against the current compiled root test executable: it rejected the absent historical benchmark with exit 1 before creating the output directory. That negative native-executable check is recorded in the external `ui-sweep-actual-preflight.json`; it is not a benchmark result. `git diff --check` passed for the changed files.

Limitations: this fixes evidence admission, not the availability of the historical benchmark in a current executable. Frozen executables exposing the historical test and emission contract remain supported; differently scoped current tests are not substitutes. GPU types other than discrete/integrated are conservatively rejected. Synthetic transcripts establish driver behavior, not measured GPU performance, native-worker behavior, current host presentation rate, or corpus-wide control coverage.
