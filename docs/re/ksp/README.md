# KSP map

`SYMBOLS.tsv` and `COVERAGE.md` are generated by `tools/re/ksp_symbols.py sync`.

## KSP doctor

Diagnose which KSP symbols a script uses and how KONTRA implements each one.

```sh
python3 tools/re/ksp_symbols.py doctor script.ksp            # text report
python3 tools/re/ksp_symbols.py doctor Patch.nki --json      # .nki instrument, scripts extracted via dump_scripts
python3 tools/re/ksp_symbols.py doctor a.ksp b.ksp --strict  # exit 1 if an unsupported symbol is used
```

Each symbol gets a status (`full`, `simplified`, `stub`, `unsupported`, `modern-extension`), a
diagnostic code (`KSP-FULL` ... `KSP-UNKNOWN`), conformance (`tested` / `untested`) and its corpus
rank. `full` is only reported when a conformance test exists; an untested ledger `Implemented` row is
shown as `simplified`. The summary line gives the symbol count, the percent full, and the blockers
(unsupported or stub symbols). With several inputs, `--json` also carries a per-library and
per-symbol aggregate. Tests: `python3 -m unittest tools/test_ksp_symbols.py`.
