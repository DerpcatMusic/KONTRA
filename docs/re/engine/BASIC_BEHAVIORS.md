# Basic sampler behaviours: Kontakt 8 translation completeness

Scope: the core sampler behaviours a Kontakt instrument depends on, audited statically (loader fields, IR, engine code, existing tests, Kontakt evidence in `docs/re/` and the decompile). No corpus runs or library renders were used.

Status legend:
- **covered**: loader reads the field, IR carries it, engine implements it, and a test or proved probe backs it.
- **covered (test gap)**: implemented and evidenced, but no dedicated test was located.
- **gap fixed**: a gap was found; a failing fixture test was written and the fix is in the PR named below.
- **open**: Kontakt's law or field meaning is not recovered; KONTRA keeps a documented placeholder or diagnoses it. Nothing is claimed as parity.

Evidence IDs: `KL0xx`/`KE0xx`/`KM0xx` are rows in `docs/re/kontakt-bindings/audit-probes.tsv` (oracle probes, PROVED unless noted). "Decompile" means the Kontakt 8 Ghidra export in `source/kontakt8/` (no addresses are copied into the code).

## Gap found in this audit

- **Random start criteria (row 3).** Kontakt draws once over all mode-4 rows and each row matches its own ordinal. The engine drew over groups, so two random rows of one group joined by AND could both match, and unusable rows did not take a share of the draw. Fixed in `sampler-core/src/native_start.rs`; failing fixture first, then the fix. The draw itself was a SplitMix64 placeholder. It is now the MT19937 stream with Kontakt's bounded mapping (`random(0, N-1)`), recovered from the Kontakt 8 binary.

## Open items

- Row 3: the native per-process seed (the binary seeds from `std::random_device`, so no fixed seed exists). The engine uses `reset_native_cycles(seed)` (low 32 bits), which is a KONTRA choice. The KSP evaluator of the mode-4 `random` node is not located, so the match to the builtin is assumed. Release-generated callbacks do not redraw in the engine, unlike Kontakt's documented behaviour.
- Row 4: scripts cannot reach the Kontakt RR index (scope settled from the decompile, see row 4). Only the explicit engine reset is modelled; the Kontakt triggers for that reset are not recovered.
- Row 6: the release counter's value domain (`T` in ms, frozen at note-off) is not extracted from the decompile. The current formula is the manual's wording, not a recovered law.
- Row 15: closed as linear (measured, see row 15). The decompile does not locate the audio gain path, so the law is evidenced by measurement only.
- Row 19: start-modulation units are not probed.
- Row 23: the default pitch-bend range is not probed.
- Row 27: the pedal-suite divergence is measured, not re-run.
- Exclusive group raw encoding (row 12) is consistent with the probed API domain but not probed on saved files.
