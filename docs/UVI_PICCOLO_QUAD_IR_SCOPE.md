## Implemented source scope

This review read source HEAD `46c56f9`. Relative to the requested `012f46d`, `effects.rs`, `playback.rs` and `resampling.rs` are unchanged; `library.rs` and `sample.rs` contain subsequent integration changes. These are source observations, with runtime verification pending.

- [Resource resolution](../src/uvi/library.rs#L121) resolves the preset-relative reference into the bank member path. [Initial resource collection](../src/uvi/library.rs#L186) includes Convolver/SampledReverb SamplePath. A [single-member audio resource](../src/uvi/library.rs#L282) retains its decoded channel count; only a multi-member mono bundle is assembled. The [decoder](../src/uvi/sample.rs#L596) obtains declared channel count, preserves interleaved channels and enforces dimensions, finite PCM and codec verification. These checks were not rerun against this asset body.
- [Impulse preparation](../src/uvi/effects.rs#L667) validates sample dimensions, reconstructs each ordered source channel, and keeps one Convolver per supplied bus channel. [Kernel selection](../src/uvi/effects.rs#L808) is `bus_channel % IR_channel_count`. The IR width does not enlarge the bus or create a 2-by-2 crossfeed matrix. The current Renderer [constructs global processors on two channels](../src/uvi/playback.rs#L1157), [assigns processors by nearest Keygroup ancestry](../src/uvi/playback.rs#L1235), and [passes the existing channel width through nested rack chains](../src/uvi/playback.rs#L2641). Thus these initially serialized Program-Aux owners use a stereo processor bus in the current implementation; this is not a measured native host-width assertion.
- [Convolver processing](../src/uvi/effects.rs#L829) convolves each same-numbered input channel independently. SampledReverb has separate stereo diffusion, width, windows and gain preparation; those laws do not apply to these two owners. Their disabled normalization also avoids extrapolating mono/stereo normalization evidence to a quad impulse.
- [Rate scope](../src/uvi/resampling.rs#L16) admits equal rates and the retained 44.1/88.2-to-48 kHz reconstruction scope. This header fits the latter source rate at a 48 kHz target. Header fit alone is not a fresh reconstructed-PCM comparison.
