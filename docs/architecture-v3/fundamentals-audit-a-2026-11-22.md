## P0 — Audible / Broken Core Fundamentals

### P0.1 — `ModTarget::invert` Is Completely Ignored Across All Kontakt Modulators (Internal & External)
- **KONTRA**: [modulation.rs:60-80](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/vendor/ni-file/src/kontakt/objects/modulation.rs#L60-L80) decodes the Invert button into `ModTarget::invert` separately from `ModTarget::signed_intensity()` (`unknown_flags & 2`). Searching `crates/format/kontakt/src/` for `invert` yields **zero matches** — [external.rs](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/format/kontakt/src/external.rs), [timed.rs](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/format/kontakt/src/timed.rs), and [translate.rs](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/format/kontakt/src/translate.rs) never read `t.invert`.
- **Ground Truth**: Kontakt's modulation compiler `FUN_140873040` ([0140870000.c:4072-4191](file:///data/dev/workspace/Research/KONTRA/source/kontakt8/0140870000.c#L4072-L4191)) wraps every route in `fcinv_flip(x)` (`1 - x` for unipolar sources/targets) or `fcinv_neg(x)` (`-x` for bipolar) when the target's Invert flag is set — completely independent of intensity sign.
- **Impact**: Every inverted modulation route in every Kontakt library runs backwards: velocity-inverted attack (harder hit = faster attack — ubiquitous in strings/pianos/brass), inverted CC crossfades, inverted LFOs, inverted keytracking, and inverted filter/pitch envelopes.
- **Vision-Compliant Fix**: Keep IR minimal by composing inversion at translation time into existing neutral primitives: for bipolar targets/sources negate `intensity` (or flip curve), and for unipolar sources apply `x -> 1 - x` via a single `invert: bool` flag on `ir::Mod` / curve evaluation (no vendor branches, zero RT allocation).

### P0.2 — `BParExternalMod` `bypass` Flag (`+0x53c`) Is Completely Ignored
- **KONTRA**: [external.rs:273](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/format/kontakt/src/external.rs#L273) hardcodes `bypass: false` on every external modulator; `unknown_source_data[2]` is never inspected.
- **Ground Truth**: `FUN_140d09620` ([0140d00000.c:7454-7459](file:///data/dev/workspace/Research/KONTRA/source/kontakt8/0140d00000.c#L7454-L7459)) and XML parser ([0140920000.c:1698-1711](file:///data/dev/workspace/Research/KONTRA/source/kontakt8/0140920000.c#L1698-L1711)) prove `BParExternalMod` stores `[cc_start_lo, cc_start_hi, bypass (+0x53c), simulateK2EnvTimeModulation (+0x53d)]` inside the 4-byte `unknown_source_data` read by [modulation.rs:240-248](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/vendor/ni-file/src/kontakt/objects/modulation.rs#L240-L248).
- **Impact**: Any bypassed external modulator (disabled velocity->volume, CC->cutoff, CC->attack, pitchbend, etc.) left in a patch by a sound designer silently fires at full strength in KONTRA.
- **Vision-Compliant Fix**: Expose `bypass(&self) -> bool` on `ExternalModParams` (`unknown_source_data.get(2).is_some_and(|&b| b != 0)` for assigned sources, `unknown_source_data.first()` for unassigned), and wire it to `ir::Mod.bypass` (already honored by `Engine`).

### P0.3 — AHDSR AHD-Only Mode Is Silently Dropped
- **KONTRA**: `ni-file` decodes `EnvelopeAhdsr::unknown_flag` ([envelope.rs:70](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/vendor/ni-file/src/kontakt/objects/envelope.rs#L70), documented as native AHD-only flag), yet [laws.rs:20-34](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/format/kontakt/src/laws.rs#L20-L34), [laws.rs:209-228](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/format/kontakt/src/laws.rs#L209-L228), [ir/src/lib.rs:533-550](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/model/ir/src/lib.rs#L533-L550), and [envelope.rs:11-28](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/engine/voice/src/envelope.rs#L11-L28) ignore it completely with no diagnostic.
- **Ground Truth**: `FUN_140ae40f0` ([0140ae0000.c:3170-3179](file:///data/dev/workspace/Research/KONTRA/source/kontakt8/0140ae0000.c#L3170-L3179)), `FUN_140ae5820` ([0140ae0000.c:3969-3975](file:///data/dev/workspace/Research/KONTRA/source/kontakt8/0140ae0000.c#L3969-L3975)), and `FUN_140ae5e40` ([0140ae0000.c:4197-4205](file:///data/dev/workspace/Research/KONTRA/source/kontakt8/0140ae0000.c#L4197-L4205)): when `+0x118 != 0`, Decay targets `0.0` (ignoring Sustain), key release is ignored, and finishing Decay jumps straight to Stage 5 (`Off`).
- **Impact**: Drums, percussion, plucks, and staccato one-shot groups configured in AHD mode hang at Sustain while held and cut prematurely on short key taps.
- **Vision-Compliant Fix**: Add a neutral `one_shot: bool` (or `mode: EnvMode::Adsr | EnvMode::Ahd`) to `ir::Envelope` and `voice::Ahdsr`: when set, ignore `release()`, target `0.0` in `Decay`, and transition `Decay -> Off`.

### P0.4 — Starting Inside a Loop Silently Skips the Loop (Breaks Legato/S.Mod/`play_note` Offsets)
- **KONTRA**: [zone.rs:187](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/engine/voice/src/zone.rs#L187) rejects any loop whose start precedes the adjusted `region.start`:
  ```rust
  if l.start < self.start || l.end <= l.start || l.end > self.end || l.end <= src { continue; }
  ```
  When [start.rs:101](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/engine/engine/src/start.rs#L101) advances `region.start` by a KSP `play_note` sample offset or `S.Mod`, any loop starting earlier than that offset is skipped.
- **Ground Truth**: `FUN_140960c00` ([0140960000.c:661-701](file:///data/dev/workspace/Research/KONTRA/source/kontakt8/0140960000.c#L661-L701)) only checks `playhead < loop_end` (`*(int*)(voice + 0x164) < local_res10[0]`) — never `loop_start >= sample_start`. Even KONTRA's own v2 spec ([k-sampler-source.md:62](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/docs/re/engine/k-sampler-source.md#L62)) confirms: *"Start inside a loop plays to the loop end, then wraps to the loop start (which may precede the sample start)."*
- **Impact**: Orchestral legato sustains, pad attack-skip offsets, and velocity-to-S.Mod instruments stop looping and die abruptly at sample EOF whenever the offset enters the sustain loop.
- **Vision-Compliant Fix**: Remove `l.start < self.start` from [zone.rs:187](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/engine/voice/src/zone.rs#L187); only require `l.end > l.start && l.end <= self.end && l.end > src` (and ensure preload/stream fetches cover `l.start` when wrapping back).

### P0.5 — Finite Loop Count Is Off By One (Every Counted Loop Plays 1 Extra Pass)
- **KONTRA**: [translate.rs:1020](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/format/kontakt/src/translate.rs#L1020) copies `l.loop_count` verbatim into `ir::Loop.count`, while [zone.rs:24,234](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/engine/voice/src/zone.rs#L24) interprets `count` as *"repeats after the first pass"* (`if l.count > 0 && self.loops_done >= l.count`).
- **Ground Truth**: `FUN_140960c00` ([0140960000.c:679](file:///data/dev/workspace/Research/KONTRA/source/kontakt8/0140960000.c#L679)) loads `loopCount` directly into `voice + 0x174`. On the **first** hit of loop end (`0140870000.c:7407-7408`, `7908-7909`), Kontakt decrements `voice + 0x174` and wraps only if `> 0`:
  - `loopCount == 0`: infinite loop.
  - `loopCount == 1`: `1 - 1 == 0` -> exits immediately (1 pass total, 0 wraps).
  - `loopCount == N`: `N` passes total (`N - 1` wraps).
- **Impact**: Every finite-count loop in Kontakt plays one extra cycle (`loopCount = 1` loops twice; `loopCount = 2` plays 3×), desyncing rhythmic loops and multi-loop sequences.
- **Vision-Compliant Fix**: Standardize `ir::Loop.count` as total passes (`0` = infinite, `1` = 1 pass / 0 wraps, `N` = `N` passes) — matching both Kontakt and SFZ/standard sampler semantics — and check `self.loops_done + 1 >= l.count` before wrapping in [zone.rs:234](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/engine/voice/src/zone.rs#L234).

### P0.6 — Reverse Playback Ignores Loops, `S.Mod`, `play_note` Sample Offset, and `loopStart`/`loopLength` Modulation
- **KONTRA**: [zone.rs:172-183](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/engine/voice/src/zone.rs#L172-L183) runs reverse playback in an early-return branch that completely bypasses `self.loops`. [start.rs:93,109](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/engine/engine/src/start.rs#L93) gates both `play_note` offset/`S.Mod` AND `shift_loops` behind `if !region.reverse`.
- **Ground Truth**:
  - `0140840000.c:9557-9568`: When reverse (`*(char*)(group + 0x672) != 0`), Kontakt subtracts `play_note` offset / `S.Mod` from `sample_end` (`*(int*)(zone + 0x9d4) = iVar8 - (int)fVar21`), clamped against `FUN_140884db0` in DFD mode.
  - `FUN_140880860` ([0140880000.c:554-567](file:///data/dev/workspace/Research/KONTRA/source/kontakt8/0140880000.c#L554-L567)) and `0140870000.c:7290-7315, 7853-7878`: Reverse voices still execute loops in mirrored coordinates `[len - loop_end, len - loop_start]` and apply `loopStart`/`loopLength` modulation with negated sign (`if (dir < 1) delta = -delta`).
- **Impact**: Reversed pads/swells/FX ignore sustain loops, ignore `S.Mod` and KSP `play_note` sample offsets (critical for tempo-synced reverse risers), and ignore loop modulation.
- **Vision-Compliant Fix**: Unify forward and reverse traversal in `ZoneRead` using signed direction (`dir: i8 = ±1`) and mirrored bounds (or a unified coordinate mapping), and apply offsets from `region.end` downward when `region.reverse` is true in [start.rs:93-111](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/engine/engine/src/start.rs#L93-L111).

### P0.7 — Primary (Amp) AHDSR Silently Drops All Non-Volume Targets and Ignores Its `bypass` Flag
- **KONTRA**: [translate.rs:809-835](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/format/kontakt/src/translate.rs#L809-L835): When an AHDSR has a `"volume"` target and `out.envelope.is_none()`, it consumes the entire AHDSR chunk, sets `bypass: false` (ignoring `p.unknown_flags[1]`), and **silently discards every other target** attached to that same AHDSR (e.g., an amp envelope also routed to `filterCutoff` or `pitch`) with zero diagnostic.
- **Ground Truth**: Kontakt allows any AHDSR (including the amplifier envelope) to carry up to 16 `ModTarget`s (`BParInternalMod` shares `read_targets`) and respects `bypass` (`+0x540` / `unknown_flags[1]`).
- **Impact**: Patches sharing one envelope across amp + filter/pitch lose their filter/pitch contour completely; bypassed amp envelopes stay active.
- **Vision-Compliant Fix**: In [translate.rs:809-835](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/format/kontakt/src/translate.rs#L809-L835), honor `p.unknown_flags[1]` on the amp AHDSR, and emit any remaining non-`"volume"` targets on that same AHDSR through `timed::translate` as routed modulation envelopes (sharing the same `slot` for KSP `set_engine_par`).

### P0.8 — MIDI CC120 (All Sound Off), CC121 (Reset All Controllers), CC123 (All Notes Off), and CC66 (Sostenuto) Completely Missing
- **KONTRA**: [midi.rs:24-128](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/engine/engine/src/midi.rs#L24-L128) only intercepts CC64 (sustain) and passes everything else to `behaviour.set_cc`. Searching all of `crates/app/` confirms the host/plugin wrapper does not intercept CC66, CC120, CC121, or CC123 either.
- **Ground Truth**: Standard MIDI 1.0 Channel Mode Messages (required by every DAW on transport stop/panic) and Piano/Orchestral Sostenuto (CC66).
- **Impact**: DAW stop/panic buttons leave stuck infinite-loop or sustained notes ringing forever (no CC120/CC123), controllers fail to reset on DAW playback restart (no CC121), and classical piano/harp/strings sostenuto pedal (CC66) does nothing.
- **Vision-Compliant Fix**: Handle in [midi.rs](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/engine/engine/src/midi.rs):
  - `CC120`: fast-fade/kill all sounding voices on that channel immediately (bypassing sustain/release).
  - `CC123`: release all held notes on that channel (respecting sustain if down, or releasing all non-pedal notes).
  - `CC121`: reset channel CCs (except volume/pan/bank per GM2/MIDI RP-015), pitch bend, aftertouch, and pedal latches.
  - `CC66`: on rising edge (`>= 64`), snapshot currently held note IDs on that channel into a fixed-capacity bitset/flag on `Note`; hold only those notes until CC66 `< 64`. Zero RT allocation.

### P1.1 — AHDSR Envelope Time/Level Modulation Incomplete (`hold`/`decay`/`sustain` Missing; `release` Read at Note-On)
- **KONTRA**: [external.rs:166-211](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/format/kontakt/src/external.rs#L166-L211) maps only `ahdsr_attack` and `ahdsr_release` (dropping `ahdsr_hold`, `ahdsr_decay`, `ahdsr_sustain`), and [voice_gain.rs:586-622](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/engine/engine/src/voice_gain.rs#L586-L622) evaluates `ModKind::Release` at `Age::START` (note-on).
- **Ground Truth**: `FUN_140ae46d0` ([0140ae0000.c:3357-3428](file:///data/dev/workspace/Research/KONTRA/source/kontakt8/0140ae0000.c#L3357-L3428)) modulates all 5 inputs (`0xb8` attack, `0xb9` hold, `0xba` decay, `0xbd` sustain cubed, `0xbb` release), and `FUN_140ae40f0` ([0140ae0000.c:3152-3154](file:///data/dev/workspace/Research/KONTRA/source/kontakt8/0140ae0000.c#L3152-L3154)) calls `FUN_140ae46d0(env, 4)` **at note-off** so release-velocity and live CC modulation of release time take effect on release!
- **Impact**: Velocity->decay (very common on pianos/plucks), release-velocity->release, and CC->release/decay/sustain do not work or freeze stale note-on CC values.
- **Vision-Compliant Fix**: Generalize `ir::ModKind::Attack`/`Release` into a single `ir::ModKind::EnvStage { stage: EnvStage, source, intensity, floor_ms, envelope }` covering all 5 stages, and re-evaluate `Release` routes inside `Engine::release` when triggering `voice.release()`.

### P1.3 — `Envelope::step()` Off-by-One Hold Stage, `floor > 0` Release Cliff Click, and `< 33`-Frame Attack Crush
- **KONTRA**:
  1. [envelope.rs:186-197](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/engine/voice/src/envelope.rs#L186-L197): `Stage::Hold(0)` consumes 1 extra frame at `1.0` even when `hold == 0` (every `hold == H` lasts `H + 1` frames; unit test at line 309 even compensates by ticking 101 times for a 100-frame decay).
  2.   3. [envelope.rs:113](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/engine/voice/src/envelope.rs#L113): `wait = settings.lag.min(settings.attack.saturating_sub(1))` crushes any Kontakt attack `< 33` frames (`< 0.69 ms` at 48 kHz) into `attack - 1` silent frames followed by a 1-frame step!

- **Vision-Compliant Fix**: Skip `Hold` when `hold == 0` on entry; when `floor > 0` on an amp envelope, let release target `0.0` (or keep voice alive only if `floor` is intended as unmodulated level, never snapping to 0); separate fixed control-cadence latency from attack ramp duration.

  2. ### P1.9 — Resampling Aliasing on Upward Pitch-Shift, Sample-Rate-Dependent `GAIN_SMOOTH`, & `HEAD_WAIT` Stall
- **KONTRA**:
  1. [voice/src/lib.rs:795](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/engine/voice/src/lib.rs#L795): Unfiltered 4-point Hermite interpolation for all pitch ratios (`step > 1.0` aliases strongly), ignoring Kontakt's `interp_quality` (Standard / High / Perfect) and [02-ENGINE.md](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/docs/architecture-v3/02-ENGINE.md) quality goals.
  2. [voice/src/lib.rs:41,567](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/engine/voice/src/lib.rs#L41): `GAIN_SMOOTH = 0.01` is hardcoded per-sample (2 ms at 48 kHz, 0.5 ms at 192 kHz, 4.5 ms at 22 kHz).
  3. [voice/src/lib.rs:513-529](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/engine/voice/src/lib.rs#L513-L529): `HEAD_WAIT = 2400` stalls a voice up to 50 ms waiting on `heads_pending()` + `!ready` — directly violating [02-ENGINE.md §5](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/docs/architecture-v3/02-ENGINE.md) (*"A voice never waits for storage"*) and causing **phase/onset skew across multi-mic layers** if mic A is resident while mic B waits!

- **Impact**: Audible metallic aliasing when pitching cymbals/strings/synths up an octave+, sample-rate-dependent envelope/gain zippering, and comb-filtering/flamming between close/room mics on cold-cache first notes.
- **Vision-Compliant Fix**: Use one modern polyphase/windowed-sinc resampler (with precomputed table, band-limiting when `step > 1.0`, zero RT allocs) for upward pitch shifts while keeping Hermite for `step <= 1.0`; compute `GAIN_SMOOTH` from `sample_rate` (`1 - exp(-1 / (tau * fs))`); use `base.checked_sub(1)`; align multi-mic voice starts or eliminate blocking `HEAD_WAIT` via guaranteed preload of sample heads + loop starts.

## P2 — Architectural Fragility vs Future-Proof Multisampler Vision

1. **Multi-Mic / Multi-Zone Stealing Fragmentation ([admit.rs:41-61](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/engine/engine/src/admit.rs#L41-L61))**: When `steal_whole_groups == false` (Kontakt default), stealing pops one individual voice at a time, stripping one microphone (e.g. Close) while leaving Room/Decca playing on the same note — shifting stereo image and timbre mid-phrase. Grouping sibling voices by `NoteRef` / event ID during global polyphony steals (while preserving per-group voice limits) is cleaner and musically superior.
2. **Envelope Architecture Split (Voice `Ahdsr` vs Control-Rate Breakpoint `envelopes` + `GAIN_SMOOTH`)**: [voice/src/envelope.rs](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/engine/voice/src/envelope.rs) runs audio-rate AHDSR for amp, while Flex and routed mod envelopes run at `MAX_SPAN` control rate ([engine/src/modulators.rs](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/engine/engine/src/modulators.rs)), and Flex-as-amp wraps itself in a second `fall_shape: 20.0` `flex_gate` ([laws.rs:264-277](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/format/kontakt/src/laws.rs#L264-L277)) that double-multiplies the release slope. Unifying AHDSR, AHD, DAHDSR, DBD, and Flex onto one clean audio-rate / block-linear stage machine eliminates `flex_gate`, gives UVI independent decay/release curves + true delay stage, and removes `MAX_SPAN` stair-stepping on fast pitch/filter transients.
3. **Half-Pedaling & Re-Pedaling Not Represented in Neutral Engine ([midi.rs:102-128](file:///data/dev/workspace/worktrees/matari/kontra-fundamentals-audit/plugins/kontra/crates/engine/engine/src/midi.rs#L102-L128))**: Kontakt's built-in sustain pedal is indeed binary `CC64 >= 64` via generated system script (`0140870000.c:4794-4808`), so KONTRA matches default Kontakt today — but modern pianos (SFZ/UVI/future KONTRA native format) rely on continuous half-pedaling (release-rate modulation by CC64) and re-pedaling (re-catching releasing voices when CC64 goes down). Designing `PedalState` cleanly now avoids bolting it on later.
4. **32-Bit Floating-Point Phase vs `f64` Cursor Precision**: `ZoneRead` properly uses `f64` fractional cursor (`zone.rs`), which is great — keep it `f64` when unifying reverse/loop/resampling so 30-minute stems never lose sub-sample precision.
