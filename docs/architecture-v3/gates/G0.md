# Gate G0: baseline on v3 (measured 2026-10-25, commit 9acb0f9c8)

Every later gate compares against these numbers. Raw output (text and JSON per
run) is kept in `/data/dev/workspace/PluginArtifacts/v3-gates/G0/` on the
maintainer's machine.

## Commands

```sh
cargo run -p xtask -- size
cargo run -p xtask -- debt
cargo build --profile fast -p kontra-probe
kontra-probe --fixture <cc_start|ui_load|key_position|dense|streamed> --pattern <live|dense> --json <out>
kontra-probe "<library .nki>" --pattern <live|dense|offsets> --json <out>
```

Samples Vista `Vista - 4 Violas.nki`, Conflux 1.1.0 `Conflux.nki`, ANALOG STRINGS
`ANALOG STRINGS.nki`.

### What the failures point to

- **Start offsets (C1/C9).** The worst start error is 128 frames on cc_start, 15 on
  Areia, 6 on Conflux, 135 on ANALOG and 2,936 on Vista (16 notes never audible).
  P1.1, P1.1b and P1.2 own this.
- **Cold starts (C8).** 0/64 chords are audible in their first block on Areia and
  Vista, and 63/64 on cc_start. P1.2 (preload law) owns this.
- **Voices (C6).** On Areia, no voice starts on keys 48/50/52/53 (16 of 64 notes in
  `live`, all 64 in `dense`), although the probe reports that a zone maps every key.
  Still to triage against the instrument's mapping and scripts: an engine bug, or a
  key range the probe should not use.
- **UI load (C7).** ui_load drains 16,384 script effects (the queue capacity)
  out of 19,200, and every note stays silent. P2.1 and P2.2 own this.
- **Render nulls (C4/C5).** cc_start nulls at −2.9 dB, key_position at −5.3 dB
  and ANALOG (C4) at −10.2 dB at block 1024, against a −120 dB limit.
