### Key Structural Takeaways
1. **Highest-impact audio bugs (`KT-01`–`KT-04`, `KT-06`–`KT-09`)**:
   - Modern AHDSR time modulation (`KT-01`) drops `fcubic` (`power: 3`) for external types 7–13 (Velocity, Key, Random, Constant, etc.), causing up to an **18× attack-time error** across **26,873 routes / 916 instruments** even though `ir::TimeScale::LogKnob { floor_ms, power }` and `voice_gain.rs:1096` already support `power`.
   - Runtime `$ENGINE_PAR_EFFECT_TYPE` swaps (`KT-02`) compare `std::mem::discriminant(&e.kind)` instead of Kontakt's effect type ID, silently **no-oping** whenever a script switches between two distinct Kontakt modules in the same IR family (e.g., Replika ↔ Wow/Flutter, Reverb2 ↔ Raum, Tape ↔ DStortion, Lo-Fi ↔ Bite, Solid Bus Comp ↔ Compressor).
   - Raum (`KT-03`) uses guessed laws that are **4× off on predelay** (`500·x²` vs binary `0.08·(2x)²` / `1.92·(2x-1)²+0.08` up to 2000 ms) and **~3× off on high-cut** (`1000·90^x` to 90 kHz vs binary `1000 + 23324.1·x²`), while silently dropping saved `feedback` and `reverb`.
   - `Source::Script(_)` (`KT-04`) is classified as bipolar in `external.rs:84` but omitted from bipolar normalization in `voice_gain.rs:599-635`, clipping all negative `$EVENT_PAR_MOD_VALUE_ID` values to `0.0` through shapers and envelope-stage routes (~350 corpus script slots).
2. **Root cause of drift is fragmented tables (`KT-16`–`KT-20`)**:
   - Effect identity, binary layouts, KSP `$ENGINE_PAR_*` laws, and display readouts are split across **6+ registries** (`effects.rs::MODULES`, `effects.rs::slot_effect`, `drive.rs`, `engine_pars.rs::OWNERS`/`FIXED`, `script_knobs.tsv`/`script_knobs.rs`, `held_fields.tsv`/`held.rs`, `readouts.rs`, `kontakt-effects::module::ALL`, and `vendor/ni-file::effect_parameters.rs`).
   - This fragmentation directly produced `KT-05` (13 Replika controls stuck in `Held`), `KT-06` (Compressor load vs KSP law mismatch), `KT-07` (`$ENGINE_PAR_CH_DEPTH` left in `Opaque` after Legacy Chorus was implemented), `KT-12` (Phasis/Tape dead knobs), and `KT-17` (6 modules parsed 2–3× per slot at load).

## Detailed Analysis

### 1. Wrong Translations (`KT-01` – `KT-15`)

#### `KT-01` — Modern AHDSR time modulation drops `fcubic` (`power: 3`) for external types 7–13 (`proven`)
- **Files**: `crates/format/kontakt/src/laws.rs:187-196`, `crates/format/kontakt/src/external.rs:128, 145, 408-416`, `crates/engine/engine/src/voice_gain.rs:1089-1101`.
- **Evidence**: `docs/re/kontakt-envelope-time-modulation.md:62-81` proves from `Kontakt8.exe` ([ref] & [ref]) that on all Family H targets (including `0xb8..0xbb`: `ahdsr_attack`, `ahdsr_hold`, `ahdsr_decay`, `ahdsr_release`, and `ahdsr_sustain`), modern Kontakt (`simulate_k2 == false`) selects `fcubic(1 - (1 - E)·i)` (`power: 3`) for external source types 7..=13 (KeyPosition, Velocity, ReleaseVelocity, ReleaseTriggerCounter, Constant, RandomUnipolar, RandomBipolar) and identity (`power: 1`) for types 1..=4 (PitchBend, PolyAT, MonoAT, MidiCc), Script (5), and internal sources.
- **Bug**: `ir::TimeScale::LogKnob { floor_ms, power }` and `voice_gain.rs:1096` (`multiplier.powi(i32::from(power))`) ALREADY support `power`, yet `laws::time_scale(simulate_k2: bool)` (`laws.rs:187-196`) ignores the source and hardcodes `power: 1` when `simulate_k2 == false`.
- **Quantitative impact**: On a 1000 ms attack with Velocity→Attack at intensity 1.0 and velocity 64 (`m = 0.5`):
  - Current (`power: 1`): `2 · 501^0.5 - 2 = 42.8 ms`
  - Kontakt (`power: 3`): `2 · 501^0.125 - 2 = 2.35 ms` (**18.2× error**).
  - Corpus impact: **26,873 AHDSR time routes across 916 instruments** (`kontakt-envelope-time-modulation.md:11`).
- **Related sustain bug**: `external.rs:416` hardcodes `ir::Curve::Depth { power: 3 }` for `ahdsr_sustain` regardless of source. For un-cubed sources (CC, PitchBend, Script), scaling sustain knob `u` by `m` yields `S' = (u·m)³ = S·m³` (`power: 3`, correct). For cubed sources (Velocity, Key, Random), `u` is scaled by `m³`, yielding `S' = (u·m³)³ = S·m⁹` (`power: 9`).

#### `KT-02` — `$ENGINE_PAR_EFFECT_TYPE` swap fails on `EffectKind` discriminant collision (`proven`)
- **Files**: `crates/engine/engine/src/fx_types.rs:114-126`.
- **Bug**:
  ```rust
  let same = match subtype {
      false => holds.is_some() && holds == kind(&effect), // std::mem::discriminant(&e.kind)
  ```

#### `KT-03` — Raum (`0x65`) guessed laws vs binary-confirmed Kontakt 8 laws (`proven`)
- **Files**: `crates/format/kontakt/src/raum.rs:20-64, 83, 86`, `crates/format/kontakt/src/effects.rs:443-456`.
- **Evidence**: `docs/re/engine/k-raum-cosmic-laws.md` (binary `Kontakt8.exe` `141982050`, `141981200`, `141982250`):
  - **Predelay**: `raum.rs:57` computes `500.0 * x * x` (`x=0.5 → 125 ms`, `x=1.0 → 500 ms`). Binary `141982050` computes `0.08 * (2x)^2` s for `x <= 0.5` (`x=0.5 → 80 ms`) and `1.92 * (2x - 1)^2 + 0.08` s for `x > 0.5` (`x=1.0 → 2000 ms`, **4× error**).
  - **High cut**: `raum.rs:58` computes `1000.0 * 90f32.powf(x)` (`x=0.5 → 9487 Hz`, `x=0.95 → 71871 Hz`, `x=1.0 → 90000 Hz`). Binary `141981200` computes `1000 + 23324.1 * x^2` Hz for `x <= 0.95` (`x=0.5 → 6831 Hz`, `x=0.95 → 22050 Hz`), else `22050 + 1764000 * (x - 0.95)` Hz.
