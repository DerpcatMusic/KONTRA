# Prepared v1 voice bridge: contract and remaining consumers

Exact base `54d9a5c5`; checked W6 evaluator `4507cb1e` cherry-picked as `6496f199`. Source-only contract, not a production admission claim.

The IR retains original f32 AHDSR times/curve/sustain and AHD flag in `SourceIndices.ahdsrs`, indexed by physical group and internal slot. `native_amplitude` requires the literal pinned `0cb7a8a0:src/modulation.rs` primary wrapper, default packed time records, enabled/retriggered source flags and a single untransformed unity-volume target. Arbitrary envelope/module geometry cannot be inferred from normalized curves. Ordinary conversion divides f32 milliseconds by 1000 and ignores the saved AHD switch; admitted native primary conversion multiplies f32 `.001` and applies AHD, exactly as v1 `src/engine/bank.rs`. Typed generic IR sources/routes remain present.

Preparation must assemble one immutable `ControlPlan` per admitted native group, mapping physical source/target identities before audio begins. Script initialization and snapshot setters must be overlaid in the same native setter law before that plan is frozen; raw saved values alone cannot stand in for the initialized control state. Native LFO count/note-value/phase, Flex directional curve values, external assignment order and table sampling still need forward descriptors; they cannot all be reconstructed from the normalized IR. Admission must reject the whole native voice when any executed source, route, processor, tap, live setter or playback geometry cannot be represented. The full v2 path remains the consumer for that voice.

The native voice state uses caller-owned, fixed storage. Reset copies prepared coefficient templates and uses the original note/controller stamp; release follows the pinned consumer timing. Rendering receives separate amplitude, Flex, volume-LFO and fixed-point pitch-position arrays. Preview copies the pitch clock; actual rendering advances it once. Amp/Flex/fade/volume multiplication keeps v1 order. Native `amplitude_control_point` reads the published source point, while `amplitude_level` reads the interpolated audio value.

Filter state remains independent from pitch state even when both address one envelope. Its copied ordinary envelopes and external lag values advance once, then the filter reads held values at the pinned CONTROL=32 grid. Bypassed source clocks and disconnected targets retain their separate v1 behavior. Coefficient/filter-class keys change only when the physical knobs or control values change.

The v1 render unit gathers a bounded virtual source window once, performs Hermite interpolation and mixing in its fused loop, and runs grouped filters for compatible lane keys. The port must retain each voice's filter end state using the pinned lane state-space/impulse weights; merely summing generic filtered voices is not that implementation. Streamed cursor admission, loops, event boundaries and full resident octave access must use existing v2 readiness/residency ownership. Bank interpolation remains for ratios outside the admitted v1 range. W6's checked wavetable port `61158054b809bb89f650e6659b32798517a33c21` forwards `Group.wavetable` → `Playback.wavetable` → `Cursor`. Future ordinary-sample native admission must reject `Cursor.wavetable().is_some()` before entering the fused Hermite sampler path: table phase/position and oscillator pitch are different source geometry. Its rare-geometry template storage and lazy full-cycle residency pin stay owned by that oscillator path. Live wavetable writes remain diagnostic until W5's shared physical bindings/consumer exist; this descriptor does not prove those writes are supported. W6 leaves `render_run`, resample and mix unchanged. No native whole-voice caller is currently enabled.
