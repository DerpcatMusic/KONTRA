# UVI source properties and execution qualification

A promoted ConstantModulation definition retains its structural source owner and
one pair of Value/Style control identities. References to that definition share
those controls; a similarly named definition in another owner does not. Current
values belong to the actual Core plan generation. A script-listener broadcast is
still an event for its then-sounding audience, not a seed for future notes.

The raw Value getter retains the accepted finite f64. The explicitly declared
Core target-read model clamps its source point to [0, 1], applies Style's strict
`value > 0.5` threshold when enabled, and applies bipolar conversion once. It
uses the existing route evaluator and control clock. This does not establish
UVI's native smoothing, cache, reset or callback cadence. Normal translation
retains `UnqualifiedNative`; the explicit `declare_core_constant_target_reads`
construction API selects a Core law and does not certify a commercial preset.

Property-only standalone binding validates the real Runtime and Plan before
acceptance. It grants neither MIDI/Play authority nor a plan lifetime lease.
Captured production callbacks require their actual Core turn; canceled/stale
turns cannot retain owner writes, move waiters, seed controls or substitute a
legacy command queue. Staged construction leaves initialization and spawned
roots unexecuted until their real source tasks and owner acknowledgments exist.

A parameter-bound UI field without canonical readback is disabled and has no
editable control value. The preparation interface is a snapshot, not a live
value acknowledgment. Endpoint binding acknowledges routing metadata first;
subsequent serviced Core readback publishes the real value. Presentation refresh
runs no authored changed/controller callback and advances no audio clock.

Global Program/Layer controller routes retain their source owner and actual bus
outlet instead of cloning routes onto players. Ordinary UVI attachment and
assembly still refuse these routes before eager-script/Part publication until
the receiver/actor installation exists. Explicit caller-owned Core construction
can exercise its declared source law with an actual bound receiver; this is a
separate qualification from ordinary native playback.

Envelope qualification is intrinsic to each actual cached definition and travels
through Ratio/Depth dependencies. Diagnostic deduplication cannot make a later
reference acceptable. Unproved AHD note-off and non-plain envelope activation
remain refused at shared Gain/Pan boundaries. Three existing functional AHD
fixtures still fail and remain positive expectations rather than expected-error
tests. Their failure is unresolved compatibility debt.

## Validation boundary

Authored fixtures cover actual property changes on held and future sources,
transaction refusal, plan retirement, MIDI precision, source-task cancellation,
real owner handoff and UI readback. Local voice ramps retain the established
end-of-sample law; global outlet projections retain their own absolute-time law.
Endpoint and irregular-partition checks distinguish the two without adding a
Constant-specific smoothing period. The original scripted Constant playback
regression now passes. These results do not qualify VWinds/Augmented Orchestra
sound or native UI, full host-worker delivery, or unrestricted loading.
