Install

Download KONTRA for your system. Alpha builds may change saved-state formats; keep project backups.

Windows

Extract the ZIP. Run the standalone executable, or copy the CLAP/VST3 bundle into your DAW’s plugin directory and rescan. Keep the bundle intact.

macOS

Run the universal PKG installer. Check the release notes for signing and notarization details. For a DMG release, open it in Finder before copying its contents.

Linux

Extract the ZIP. Copy the intact plugin bundles to ~/.clap or ~/.vst3, or your host’s configured path. The standalone executable runs directly.

Libraries

Add library folders in Settings, then load an instrument from the browser. Report shows missing samples and unsupported features. KONTRA includes no sample libraries.

Playback support varies by instrument. Check compatibility.

Interface scale: Settings, from 100% to 200%. All editor preferences.

Troubleshooting

An instrument sounds wrong

Check Report, then the part’s MIDI channel, output, mute/solo and level. Include the instrument and a repeatable example when reporting a problem.

Missing samples or resources

Check library paths and keep the original folder/archive structure. Include the exact error so missing files can be distinguished from decoding failures.

KONTRA does not appear in the DAW

Confirm the platform and plugin format, check the host’s search path, then rescan. Keep the plugin bundle intact.

Report a bug with the build, OS/DAW, instrument and steps to reproduce.
