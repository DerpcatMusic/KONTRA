Installation

Download from the latest release. The release manifest identifies the source and packaged artifacts. Choose standalone for an independent application, or CLAP/VST3 for a compatible DAW.

Windows x64

Download and extract the Windows ZIP. Use the included standalone executable or place the included plugin bundle in your host’s configured plugin directory, preserving the bundle structure. Rescan plugins in your DAW.

macOS · Apple Silicon and Intel

Download the universal PKG and run the installer. Inspect the release’s notarization information and installation notes. If a release offers a DMG instead, open it in Finder before copying its products so Gatekeeper can ingest the ticket.

Linux x64

Extract the Linux ZIP and keep plugin bundles intact. Place the CLAP or VST3 bundle in your host’s search path, then rescan. Common user paths are ~/.clap and ~/.vst3; your host may use a different configuration. Run the included standalone executable for use outside a DAW.

Your first session

  1. Open the standalone application or create a KONTRA plugin instance in your DAW.
  2. Use Settings to configure the locations of your installed, legally usable libraries.
  3. Browse or search the library panel, then select an instrument or multi to load into the rack.
  4. Check the Report view for missing resources or unsupported behavior before evaluating playback.
  5. Send MIDI from your host or controller, or use the on-screen keyboard. Start at a modest listening level.

A library appearing in the browser is not a guarantee that its scripts, resources and sound engine are supported. No commercial instruments or sample libraries are included with KONTRA.

The workspace

Library browser

The left panel separates Kontakt and Falcon/UVI content, with search and a library/preset list. Library discovery and playable compatibility are distinct.

Rack, Mixer and Report

The rack organizes loaded parts. The mixer exposes the available mixing view; the Report view helps explain load and runtime limitations. MIDI channel, output and part controls sit alongside each instrument.

Instrument views

The supplied interface shows Interface, Mapping, Sound and Info tabs, plus Original, Vector and KONTRA presentation choices. Availability and control behavior depend on the instrument and build. A visible control does not establish full vendor-equivalent interaction.

Scale and keyboard

Settings offers Interface scale choices of 100%, 125%, 150% and 200%, plus Reset. This scales the complete interface independently of the instrument performance view. The on-screen keyboard provides a direct way to audition notes.

Compatibility

Kontakt playback is experimental. Scripts, effects and interfaces are partial. The public README describes Falcon/UVI metadata inspection rather than general playback. The separate v2 runtime has tested slices, but its architecture label is not a shipped product version.

Troubleshooting

An instrument loads but does not sound right

Check the Report view for script faults, missing samples and unsupported source/DSP behavior. Confirm MIDI reaches the intended rack part and inspect its output, mute/solo and level. Report the smallest repeatable case; a successful load is not a sound-equivalence check.

Samples or resources are missing

Confirm the library is installed and its paths are accessible. Keep its original directory and archive structure. Record the exact error; missing files, unsupported layouts and failed decoding are different problems.

The DAW cannot find KONTRA

Check that you downloaded the correct platform artifact and installed a format your host supports. Preserve the plugin bundle’s contents, confirm the host search path and rescan. Include the host name and version if discovery still fails.

Make a useful bug report

Include the exact KONTRA build identity, operating system, host/version, instrument name, steps, expected result and actual result. Review diagnostics before sharing them. Keep credentials, library access metadata, private paths and proprietary presets/samples out of public attachments.
