Kontakt · formats
FeatureSupportScope and gaps
NKI instrument loadingPartialImporter builds groups/zones and selected native state. Unsupported sources, inserts and modulation can leave an instrument only partly functional.
NKS / NIS preset wrappersImplementedContainer reader unwraps supported presets; bounded input, expansion and nesting. Not every NI container type.
NKM multi loadingPartialMulti reader reads parts; import warnings explicitly exclude native multi routing, master processing and multi scripts.
Instrument-bank program switchingMissingMulti reader rejects slots containing multiple programs. NI's NKB bank switching requires that behavior; direct NKB loading is also unverified.
NKSN snapshotsPartialSnapshot reader needs the base NKI and matching identity; not a standalone instrument or universal saved-state restoration.
NKX / NKR resource accessImplementedResolver reads supported archive members as virtual paths; sample test exercises decoding. Not every archive layout/cipher.
Protected library accessPartialAccess metadata supplies keys from local library metadata; sample access rejects unavailable keys and legacy NKX cipher paths. No blanket protected-library support.
WAV / AIFF sample loadingImplementedAudio reader decodes supported mono/stereo PCM files.
NCW sample loadingImplementedNCW reader decodes supported mono/stereo lossless samples.
Multichannel sample filesMissingSample reader rejects more than two channels, unlike NI's multichannel WAV/AIFF support. This is separate from multiple host outputs.
Missing-sample resolutionPartialResolver tries relative/archive paths and unambiguous suffix matches; ambiguous names fail. Native interactive relinking and resaving are not established.
NKP / NKC / NKL parityPartialNI lists script/module presets, cache files and Leap kits. Preset discovery establishes NKI/NKM/native paths; these other native workflows remain unverified, not implied by KONTRA's own cache.
Build libraries from loose samplesImplementedCreator scans WAV/AIFF, plans mappings and writes native instruments, samples and a library manifest.
Generate NKI / SFZ instrumentsPartialCreator writes selected generated group/zone/script state and SFZ. Arbitrary Kontakt instrument editing/export equivalence is not established.
Native start-record preservationImplementedCompatibility evidence records roundtrip preservation; preserving bytes does not execute every start criterion.
Playback · samples
FeatureSupportScope and gaps
Key / velocity mapping and transpositionImplementedVoice creation applies sample rate, root/key tracking and tuning. Pitch changes playback rate.
Sample interpolationImplementedVoice reader uses four-point Hermite interpolation; no claim of matching NI's interpolation modes.
Reverse sample playbackImplementedPlay map starts at the end marker; copy path reverses frame runs.
Forward loops / release tailsImplementedLoop map and release handling support the selected wrap/until-release paths.
Alternating / ping-pong loopsImplementedLoop map reflects the path and handles release without duplicating endpoints.
Loop crossfadesPartialMap blends forward boundaries; bank preparation converts alternating-plus-crossfade to forward crossfade.
Reverse combined with ordinary loopsPartialMap cycles reverse playback only for alternating loops; other combinations need reference fixtures.
Multiple active loops per zoneMissingZone and play map retain one optional loop, versus NI's multiple regions.
AHDSR envelopesImplementedEnvelope tests exercise block-independent rendering, finite release and no heap allocation.
Flex / pitch / filter envelopesPartialVoice runtime and modulation import implement selected paths; extra modes, targets and loop/one-shot semantics remain incomplete.
Disk streaming / RAM playbackPartialStreaming modes support resident heads, streamed tails and RAM-first loading; RAM budget overflow can stream. Not NI's complete per-group DFD controls.
Adaptive preload / residencyImplementedResidency assigns hot/base/cold tiers under memory pressure; this is KONTRA's policy.
Bounded streaming cacheImplementedStream tests exercise reader/block caps and eviction. Disk underruns can still cause silence.
Large sample-start offsetsPartialStreaming and voice boundary supports offsets; real-disk onset timing remains unverified.
Polyphony and voice stealingImplementedPlayer makes room for voices; engine limits and load shedding bound capacity. Not a universal performance guarantee.
Time / Tone / Beat Machine enginesMissingVoice playback changes traversal rate for pitch; independent stretch, granular formants and beat-slice engines are not implemented in this path.
Time Machine ProMissingKSP calls explicitly report unavailable stretch/voice allocation, separate from disk streaming.
Kontakt wavetable playbackPartialAdmission allows tracked 2048-frame cycles and linear/ASYM2MP forms. Phase randomness, inharmonic/audio-rate modulation and other forms are rejected; quality/anti-aliasing parity is unverified.
Modulation · MIDI
FeatureSupportScope and gaps
Imported modulation assignmentsPartialDecoder preserves readable slots and reports unsupported categories/shapers; preservation alone does not modulate audio.
Saved sine Multi LFO → pitchPartialAdmission and clock implement selected retriggered sine-only paths, phase and legacy fade.
Saved sine Multi LFO → volumePartialAdmission requires one target, zero source fade and nonnegative lag; target runtime applies the selected volume law.
LFO live depth / bypassPartialParameter routing supports admitted pitch-target depth and source bypass. Volume intensity and live source timing/frequency/phase remain unsupported.
General LFO waveforms / free-running modesMissingClock boundary explicitly excludes other waveforms and free-running clocks. Selected saved timing does not imply full tempo-sync or live-clock parity.
Envelope target depth / bypassPartialModulation and parameter routing support known targets; unknown laws, polarity/mode fields and additional targets remain gaps.
MIDI note on/off and channel ownershipImplementedEngine handles channel/owner-aware notes and releases.
CC / pitch bend / aftertouchImplementedEngine controller paths cover CC, bend, channel and poly pressure; authored script behavior can still be partial.
Sustain / release-group behaviorPartialPedal handling and release triggers implement selected ownership/release paths; every saved group condition is not established.
MPEPartialArticulation test exercises per-note bend/pressure/CC74 and RPN bend range. Broader device/host negotiation needs validation.
App articulation keyswitch routingPartialRemapping test exercises app routing; this does not execute imported native Start on Key conditions.
Native key / controller / round-robin / random group startsMissingImporter explicitly retains these records without evaluating them. KSP-driven selection is a separate path.
Legato behaviorPartialTiming test exercises articulation/channel scheduling; full note-transition sample switching is not established.
General external modulation matrixPartialAssignment runtime handles a bounded source/target subset, with eight volume/pitch assignments per voice; retained unsupported routes may have no audio effect.
Native step modulationMissingInternal-modulator import skips undecoded kinds; the audited player has no native step-sequencer path. Scripts can implement separate sequencing behavior.
DSP · filters and effects
FeatureSupportScope and gaps
LP / HP / BP, 2- and 4-pole filtersImplementedType dispatch maps the supported standard and alias IDs.
Notch / legacy 6-pole LP filtersImplementedType dispatch includes selected IDs; newer SV 6-pole HP/BP/notch forms are missing.
Phaser filterPartialModel implements notch geometry but omits resonance feedback.
Ladder / analog ladder filtersPartialType dispatch includes Ladder LP4; remaining LDR variants and HQ oversampling are missing. The saved HQ flag uses single-rate DSP with a warning.
Adaptive Resonance filtersPartialModel supplies compensated linear ladder responses; NI's input-level-dependent resonance adaptation is missing.
DAFT filtersPartialType dispatch uses linear LP/HP proxies; not the complete NI model.
Formant filterPartialType dispatch includes Formant; type 1 uses three vowel-positioned bell bands; Formant 2 is missing and NI model equivalence is not certified.
3x2 Versatile filtersMissingType dispatch excludes type 19; no three-band morph/shift/bypass/gain model.
Dedicated parallel / composite filtersMissingType dispatch excludes the native multi-filter topologies; serial insert processing is not a parallel filter model.
Monark / Dual SKF / PRO-53MissingType dispatch lacks these subtypes and their FM/feedback models; unsupported IDs pass through with warnings.
Every Kontakt filter subtypeMissingCapability warnings identify unsupported IDs/pass-through. Script constants and preserved subtype IDs exceed DSP coverage.
Group filter / EQ insert orderPartialGroup stages support eight slots, bounded sections and decoded Amplifier splits; unknown placement/families remain gaps.
EQ / Solid G-EQPartialBlock dispatch provides rack filter/EQ and Solid G-EQ paths; full model/control equivalence is unverified.
Gain / stereo / send-level stagesImplementedProcessor handles taps/sends and stage construction handles gain/stereo. Placement support remains scoped to implemented chains.
Standard delayPartialDelay defaults and dispatch implement the core delay; bounded delay length and incomplete NI control parity.
Chorus / flanger / phaser effectsPartialBlock dispatch runs the base Sweep/Phaser DSP; not Choral/Flair/Phasis parity.
Distortion / Lo-Fi / Skreamer / tape saturationPartialDrive dispatch supplies kernels; group warnings identify omitted damping and unverified saturation-mode transfer.
Compressor / feedback compressor / limiterPartialDynamics dispatch implements these kernels; full NI parameter and reference-render parity is unverified.
Solid Bus Compressor / Transient MasterPartialBlock dispatch implements stages; group placement needs a decoded Amplifier split.
Algorithmic reverbPartialReverb implements predelay, diffusion, damping, modulation and decay; parameter checks identify unmapped frequency controls.
Convolution reverbPartialEligibility requires an IR; swap test preserves wet/dry. Independent early/late processing, reverse and unknown flags remain incomplete.
Replika / PsycheDelayMissingBlock inventory and stage dispatch have no DSP for these modern delay modules.
Choral / Flair / Phasis / Ring Modulator / RotatorMissingBlock inventory lacks these native modules; simple Chorus/Flanger/Phaser kernels do not replace them.
Supercharger GT / Transparent Limiter / Plate ReverbMissingDSP gate and stage dispatch provide no processing for these named modules.
Multichannel / surround convolutionMissingConvolution construction creates two convolvers, not the native multichannel/surround IR path.
Every named Kontakt effectMissingDSP gate requires an implemented stage/defaults; block inventory is a strict subset of NI's reference. Names in the enum do not make Replika/Psyche, Choral/Flair/Phasis or other modules work.
Live effect parameters / replacementPartialNormalized parameters support selected edits/readback; unknown laws, type replacement and every bus placement remain incomplete.
Scripting · KSP and Komplete UI
FeatureSupportScope and gaps
KSP compiler / VMPartialCompiler and VM execute a supported language subset; not every KSP construct/builtin.
Operators / control flowImplementedParser and compiler handle KSP expressions, if/while/continue/select and case ranges.
User functionsImplementedParser supports declarations/calls without arguments or return values, matching KSP's function contract.
Variables / arraysPartialCompiler supports six scalar/array sigils and fixed lengths; adds a 16-million-total-element ceiling.
Conditional preprocessingImplementedPreprocessor handles SET/RESET_CONDITION, USE_CODE_IF/IF_NOT and END_USE_CODE with nesting.
Kontakt Multi ScriptMissingCallback dispatch omits on midi_in; import also warns multi scripts are not restored.
Kontakt 8.12 fade-curve argumentsMissingFade calls discard the optional curve argument and use fixed fades; accepting an argument does not apply it.
Callback registration / dispatchPartialCompiler recognizes MIDI/UI/listener/PGS/persistence/async families; recognition does not prove every trigger/context.
Waits and timed listenersPartialScheduler resumes threads and listeners with bounded fuel; complete NI timing/transport edge behavior remains unverified.
Async completion deliveryImplementedRuntime delivers completion ID/status. Individual asynchronous services still need their own implementation.
PGS shared statePartialRuntime dispatches changes; broader ordering and library dependencies remain partial.
Persistent script valuesPartialRuntime and roundtrip test retain registered values; exact NKP/snapshot/code-replacement semantics are not fully established.
Engine parameter get/setPartialAddress routing implements selected normalized controls; unsupported targets are not made functional by returning a value.
NKA array file operationsPartialWorker-backed arrays and playback test load selected files; dialogs and full filesystem semantics remain incomplete.
File-selector selected-path queriesPartialPicker and callback boundary supports selected filename/stem/path. Embedded columns and navigation remain unsupported.
Standard MIDI File APIsMissingCompiler fallback diagnoses unknown load_midi_file / mf_* calls as no-op/zero; no SMF decoding/cursor service. A positive registry alone is not proof.
Zone / sample / slice APIsPartialZone calls accept GROUP/LOW_KEY/HIGH_KEY and enforce native-zone snapshot modes; other parameters, slice queries and selected event/drop arrays remain unsupported.
Array load dialogs / mode-based savesMissingArray calls explicitly reject mode-0 load dialogs and mode-based saves; explicit-path worker operations are separate.
File selector fs_navigateMissingCalls explicitly report navigation unavailable; opening a native picker does not implement previous/next callbacks.
Unknown functions / runtime faultsPartialTests exercise diagnostics/budgets; unsupported function fallback is not an implementation of that function.
Native NCKP control preparationPartialCompatibility evidence covers selected exported records and slot bindings; arbitrary schema/hierarchy/property support remains incomplete.
Komplete UIMissingCompiler diagnostic explicitly rejects load_komplete_ui; it does not provide NI's [Komplete UI][ni-komplete] framework. NCKP/fallback controls do not establish native UI execution.

Name search / clear / selectionImplementedSearch control and selection test exercise these actions.
Kontakt browser metadata parityPartialBrowser has library/search surfaces; full NI tag/bank/category/favorites/recommendation behavior is not verified by this audit.
Instrument / multi / snapshot drop loadingImplementedDrop routing queues multis/snapshots and adds or replaces instrument parts.
Loading / scan progressImplementedHeader shows fraction/sweep; scanner reports folder/item progress.
Load failures / diagnostic logsImplementedDiagnostics and Logs UI retain partial-load/failure context. A completed load does not prove correct sound.
Original / reconstructed instrument viewsPartialPerformance view renders selected authored controls/assets; fallback layout does not reproduce every instrument.
Knobs / sliders / value editsImplementedInteraction handles drag/value editing and sends script control edits.
Buttons / switches / menusImplementedInteraction handles activation and menu selection.
Panels / nested hidingPartialPanel tests verify relative placement/hiding; panels themselves do not draw a full native widget.
Labels / pictures / wallpaper / fontsPartialText and pictures support selected bitmap/state fonts and assets; exact factory metrics and arbitrary resource formats remain incomplete.
ui_tablePartialFace draws array bars; interaction excludes table pointer editing and indexed callbacks.
ui_waveformPartialWaveform path draws peaks/cursor; slice editing, slice tables and MIDI dragging are missing in this path.
ui_xy interaction / specific renderingMissingKind mapping falls back to Other; interaction supplies no XY input.
ui_level_meter live attachmentMissingFace paints a static appearance without attached levels. This refers to the imported KSP widget.
ui_wavetable visualizationMissingKind mapping lacks a dedicated renderer; a wavetable audio engine does not supply this UI.

ui_text_edit text inputMissingTyping serves value edits; control interaction excludes text-edit input.
File-selector widgetPartialInteraction launches a native picker with source epoch/base/type. Not Kontakt's complete embedded browser/navigation UI.

Mixer mute / solo / part / master controlsImplementedMixer test exercises strips, buses, mute/solo and reset.
Part MIDI port / channel assignmentImplementedMixer test exercises assignment; full host-port behavior is separately unverified.
Part output / drag-to-bus routingImplementedMixer test verifies manual selection and bus drops.
Mic / per-instrument host outputsPartialHost test exercises generated mic ports and audio delivery; arbitrary channel matrices/widths remain unverified.
Aux sends / imported routingPartialMixer test sets an aux bus; native multi routing, every send topology and placement are not restored.
Host transport into scriptsImplementedTransport test checks position, tempo, signature and stopped/seeking behavior for its fixture.
Script / host automation parityPartialScript test verifies IDs/names; every host exposure, parameter mapping and bidirectional path is not certified.
Saved state / project migrationPartialProject migration and state tests provide persistence paths. Alpha format changes and native Kontakt snapshot gaps still apply.

Linux x86_64ImplementedCI runs full Linux tests and packaging; real-library/host sound parity is not certified.

Falcon · UVIScript
FeatureSupportScope and gaps
Observed UFS2 header inspectionImplementedOffline inspector validates a bounded observed header and reports selected fields. Not a soundbank loader.
Clear UVIP XML metadataPartialInspector summarizes UVI4/Program nodes, attributes and hashes; does not interpret module semantics.
UFS mounting / member index / extractionMissingInspector report explicitly excludes directories, programs, scripts and samples. Opaque bytes are not proof of a particular encryption scheme.
UVIM multis / executable program hierarchyMissingInspector inventories XML, not Multi→Part→Program→Layer→Keygroup→Oscillator runtime objects.
UVI DMAP / dimensional mappingMissingGroundwork identifies missing UVI dimension/mapping lowering and dispatch; Kontakt groups are not equivalent.
Falcon sample playback / streamingMissingInspector reports playback_supported: false; no decoded UFS sample/program route into the player.
Falcon analog / FM / additive oscillatorsMissingVoice source model provides sample/optional Kontakt wavetable state, not Falcon's generated analog, operator or partial engines.
Falcon granular / wavetable oscillatorsMissingGroundwork has no Falcon grain scheduler or native wavetable lowering; Kontakt's table path is a different module.
Falcon physical-model sourcesMissingVoice source model has no Pluck, Bowed String or Harmonic Resonator engine.
Falcon step envelopes / arpeggiatorMissingRuntime groundwork lacks UVI modulator/event-processor execution; KSP sequencing is a separate feature.
Falcon filters / effects / modulationMissingInspector retains metadata without executing the module graph or scoped routing.
UVIScript Lua language / host APIMissingRuntime boundary identifies separate Lua 5.1/UVI bindings; the implemented script runtime is KSP.
UVI event forwarding / coroutine schedulingMissingEvent boundary needs onEvent, forwarding and coroutine semantics; KSP callbacks are a different contract.
UVI async sample / IR / MIDI operationsMissingGroundwork requires UVI operation IDs, scope and completion behavior; existing KSP workers do not expose these APIs.
UVI widgets / parameter bindings / callbacksMissingUI boundary requires typed float/bool/table state, UVI widgets and bidirectional binding; KSP integer controls do not supply them.
UVI persistent widgets / onSave / onLoadMissingRuntime boundary identifies missing state/restore ordering and custom Lua data handling.
VWinds / H.A.T. / modeled articulation parityMissingEvidence boundary has no executed bank/runtime/reference render; shared expressive primitives do not implement proprietary modeling.

The roadmap describes the next work. The compatibility checklist goes deeper into validation limits. A script warning, missing resource or unsupported effect can affect a whole instrument.
