## Direction contract

Mode: Operate.

Extend the Graphite Rack into an offline inspection workbench. Preserve neutral
selection, square controls, flat surfaces and readable diagnostics. Use monospace
only for actual code and numeric records.

The main task is to trace authored source to classified host bindings, converted
structure and initialized UI models. Keep Problems, Source & lowering, Converted
structure, UI projection and Source metadata directly reachable. Every problem
with a recorded script coordinate opens its line and lowering record. Preserve
typed categories, implementation owners and spec references.

Runtime execution, audio, native equivalence and rendered UI fidelity have separate
evidence states. An available static binding does not mean it executed. Empty
diagnostics do not prove compatibility. Initialization is optional and read-only;
source text is optional and held in memory. No decorative asset or invented UI
preview substitutes for the library's real projected model.

Verification: authored reports exercised source escaping, problem navigation,
lowering, converted records, UI gaps and memory clearing in the shared browser.
Desktop (1280px) and narrow (360px) source views had no page overflow or console
errors in the final bounded preview pass. The static detector misidentified
inherited foreground/background values; the actual browser computed #e8e8e8 on
#1b1b1b and retained the explicit Noto Sans stack. Source metadata is never inserted
as HTML. The memory server and read-only initialization boundary have focused
tests.
